Model Architecture & Training

The backend CNN model is built using Convolutional, MaxPooling, Flatten, and Dense layers, optimized with Adam and categorical cross-entropy loss.

CNN Pipeline

The model starts with an input layer of 224 × 224 × 3, followed by Conv2D layers that learn patterns like edges, spots, and textures, ReLU activations for non-linearity, and MaxPooling to reduce spatial size while keeping key features.

Dense & Softmax

After flattening, Dense layers act as the decision maker, combining learned features to assign probabilities to each of the 38 disease classes. The Softmax output layer provides a probability distribution over all classes.

Training Setup

The model is trained with the Adam optimizer, categorical cross-entropy loss, 5 epochs, and a batch size of 32, allowing efficient learning over the PlantVillage dataset while keeping training stable.

PlantVillage Dataset

PlantVillage provides over 50,000 leaf images covering 38 disease classes across 14 crop species such as Apple, Grape, Potato, and Tomato, with both diseased and healthy leaves.

Key Stats

  • Images: ≈ 50k+
  • Crops: 14 species
  • Classes: 38 disease/healthy classes
  • Source: PlantVillage

Typical Classes

Examples: Apple Scab, Grape Black Rot, Corn Northern Leaf Blight, Squash Powdery Mildew, Strawberry Leaf Scorch, Tomato Target Spot, Tomato Mosaic Virus, and multiple “healthy” classes.
